Mongol Huleg Privacy Policy

Last Updated: August 29, 2026

Welcome to Mongol Huleg, developed by Andar Studio. This Privacy Policy explains how we collect and use information.

1. Information We Collect

We may collect:

  • Firebase User ID (UID)
  • Player name
  • Google Login or Anonymous Login information
  • Horse data
  • Coins
  • Diamond health
  • Race progress

2. How We Use Information

  • Create player accounts
  • Save game progress
  • Provide multiplayer features
  • Prevent cheating
  • Improve game performance

3. Authentication

Mongol Huleg uses Firebase Authentication. Each player receives a unique UID that cannot be changed.

4. Multiplayer

Mongol Huleg uses online services for multiplayer races, player synchronization, and tournaments.

5. Security

Players cannot directly modify coins, diamonds, horses, or rewards. Security systems are used to protect game data.

6. Chat

Chat messages may be temporarily stored for multiplayer communication and moderation.

7. Third Party Services

Mongol Huleg may use:

  • Firebase
  • Photon
